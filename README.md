# SV Summary Screen

Plugin para modificar las pantallas de datos de los Pokémon con el estilo visual de los juegos Escarlata y Púrpura.

En caso de que uses uno de estos plugins adicionales:
- Dinamax
- Mementos
- Teracristales

Debes añadir también a tu proyecto la carpeta correspondiente dentro de "Plugins opcionales". Arrástrala entera a la raíz del proyecto.
